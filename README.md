ASMARA Plus is a fork of the previously deleted ASMARA (Automated System for Monitoring And Relaying Alerts) Emergency Alert System sponsored by the Open Paging Server Organization. The goal is to finsh the deleted project with new features, and better stability.

## Why are we creating this?

ASMARA was created mainly as a toy for EAS enthusiasts by enthusiasts. The project however, was abandoned several years ago. Come to recently... A certain company due to "material shortages" discontinued their blue Encoder/Decoder.  Leaving broadcasters in a tough spot. Recently, a petiton was filed to the FCC by the National Association of Broadcasters to allow software-based Encoder/Decoders.

Right now, ASMARA Plus is still just a hobbyists toy due to it's nature. However, this project exists not only to finish the unfinished project, but also so that if a software encoder/decoder thats also open-source were to become legal to use, then the Open Paging Server Project will have the base to create a new open-source EAS solution that could be possibly become produciton-ready and approved for use. Expanding it's portfolio beyond public address. 
That is, if it would ever become legal.
